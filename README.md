# ታናኽ — ትርጉም ብትግርኛ (selah-ti)

እዚ ትርጉም ናይ ቅዱሳት መጻሕፍቲ ዕብራይስጢ (ታናኽ) ብትግርኛ እዩ። ነፍሲ ወከፍ
ጥቕሲ ኣብ ናይ ገዛእ ርእሱ ፋይል ኣሎ፤ ነፍሲ ወከፍ `token` ድማ ምስቲ ናይ
ዕብራይስጢ ቃሉ ተኣሳሲሩ ኣሎ።

**ኣጻሕፋ: ፊደል ግእዝ።** ቋንቋ: ስሩዕ ጽሑፋዊ ትግርኛ፣ ከምቲ ኣብ ኤርትራን
ትግራይን ዝጽሓፍ።

## ዕብራይስጢ — ቅድሚ ኩሉ

እዚ ትርጉም ናብ ዕብራይስጢ ንኽመርሓካ ኣሎ — ኣብ ክንዲ ዕብራይስጢ ክኸውን
ኣይኮነን። እቲ ደጋጊምካ ዝንበብ ዕብራይስጢ እዩ፦ ፊደላቱ፣ ድምጹ፣ ምልክታቱ። እቲ
ጽሑፍ ትግርኛ መስኮት እዩ፣ ተካኢ ኣይኮነን። ኣብ ዝፈላለዩሉ ቦታ፣ እቲ ሓቂ ኣብ
ዕብራይስጢ እዩ።

## ኣቃውማ ፋይላት

```
<መጽሓፍ>/<ምዕራፍ>/<ጥቕሲ>.json
```

ኣስማት መጻሕፍቲ ኣብ ፎልደራት ብእንግሊዝኛ ተጻሒፎም ኣለዉ: `genesis/1/1.json`፣
`psalms/33/12.json`።

ነፍሲ ወከፍ ፋይል:

```json
{
  "translation": "እቲ ጥቕሲ ምሉእ ኮይኑ ከም ዝንበብ",
  "tokens": [{"surface": "ቃል ዕብራይስጢ", "gloss": "ትርጉም ብትግርኛ"}]
}
```

`surface` — **ገጽ**፣ መዝገብ ዕብራይስጢ። ንሕና ክንጽሕፎ ኣይኮነን፤ ካብቲ
መሰረታዊ ጽሑፍ ይመጽእ፣ ኣይቅየርን።

`gloss` — **ግሎስ**፣ ናይዚ ሓደ `token` ዕብራይስጢ ትርጉም ብትግርኛ። ቁጽሪ
ግሎስ ምስ ቁጽሪ ቃላት ዕብራይስጢ ማዕረ እዩ። ወትሩ።

`translation` — **ትርጉም**፣ እቲ ሓደ ጥቕሲ ኣብ ቦታኡ ኮይኑ፣ ብትግርኛ ተፈጥሮኣዊ
ኮይኑ ክንበብ።

`marks` — ኣብ `token` ናይ ⟨את⟩ ጥራይ: እቲ ⟨את⟩ ዝጠቖሞ ቃል ትግርኛ።

## ቅንፍታት ማእዘናዊ ⟨ ⟩ እንታይ ማለቶም እዩ

ቅንፍታት ማእዘናዊ ንኽልተ ዝተፈላለየ ስራሕ ይውዕሉ፣ ምፍላዮም ድማ ኣገዳሲ እዩ።

**1 · ⟨את⟩ — ምልክት ዕብራይስጢ ዘይትርጎም።** ኣብ ዕብራይስጢ אֵת ንእሽቶ ቃል
ኮይኑ፣ ቅድሚ እቲ ብግሲ ዝግበር ነገር ይመጽእ። ትግርኛ ማዕረኡ ቃል የብላን፣ ብዙሓት
ትርጉማት ድማ ብስቕታ ይሓልፍዎ። ንሕና ከም ዘለዎ ንዕቅቦ — ክፋል ህንጻ ዕብራይስጢ
እዩ። ጌጋ ሕትመት ኣይኮነን፤ ኣብቲ ጽሑፍ ዘሎ ቃል እዩ። እቲ ምልክት ስድራ ኣለዎ:
את ሓደ ሓደ ግዜ ምስ ቅጥያ ይመጽእ (ואת፣ אתו፣ אתם) — ኩሎም ናይ ሓደ ስድራ።

**2 · ⟨ቃል⟩ — ትግርኛ ኣብ ዕብራይስጢ ዘየለ።** ምሉእ ሓሳብ ትግርኛ ደው ንኽብል
ኣብ ዕብራይስጢ ዘየለ ቃል ኣድላዪ ኣብ ዝኾነሉ፣ እቲ ቃል ኣብ ውሽጢ ቅንፍታት
ይኣቱ። ቅንፍታት፦ *እዚ ቃል ተርጓሚ ዝወሰኾ እዩ፤ ኣብ ዕብራይስጢ የለን።*

**ኣብ ውሽጢ ቅንፍታት ጓና ቋንቋ የለን።** ትግርኛ ኣሎ ወይ ምልክት ዕብራይስጢ
ኣሎ — ሳልሳይ የለን።

## እቲ ስም

እቲ ስም **ኣይትርጎምን፣ ብድምጹ ይጽሓፍ**።

| ዕብራይስጢ | ኣብዚ | ዝነጸግናዮ |
|---|---|---|
| יהוה | **ያህዌህ** | **እግዚኣብሄር**፣ **ጎይታ**፣ **ኣምላኽ** ኣብ ክንዲ እቲ ስም፣ **ይሆዋ** |
| אלהים | **ኤሎሂም** | **ኣምላኽ** ኣብ ክንዲ እቲ ስም |
| אל | **ኤል** | *ኣምላኽ* ከም ሓፈሻዊ ቃል ኣብ ክንዲ እቲ ስም |
| אלוה | **ኤሎሃ** | — |
| אדני | **ኣዶናይ** | **ጎይታ**፣ **ጎይታ እግዚኣብሄር** |
| שדי | **ሻዳይ** | **ኩሉ ዚኽእል** ንበይኑ |
| יה | **ያህ** | — |
| צבאות | **ጸባኦት** | "ናይ ሰራዊት" |
| שאול | **ሽኦል** | "ገሃነም"፣ "ሲኦል" |

**እግዚኣብሄርን ጎይታን ኣብ መጽሓፍ ቅዱስ ትግርኛ ነዊሕ ዘመን ደው ኢሎም ኣለዉ።**
ኮይኑ ግና፣ ኣብዚ የለዉ። ጎይታ ትርጉም *ማዕርግ* እዩ፣ ናይቲ ስም ኣይኮነን፤
እግዚኣብሄር ድማ ቃል ትውፊት እዩ። እቲ ጽሑፍ יהוה ኣብ ዝብለሉ፣ ክልቲኦም ነቲ
ስም ይሽፍኑ። እዚ ማለት ሕማቕ ትግርኛ እዩ ማለት ኣይኮነን — **ኣብ ክንዲ እቲ
ስም** ደው ይብሉ ማለት እዩ። ትውፊት ክሰምዕ ዝደሊ ኣብ ካልኦት መጽሓፍ ቅዱሳት
ትግርኛ ይረኽቦ። ኣብዚ እቲ ዝተጻሕፈ ደው ይብል።

**ቅድመ-ቅጥያታትን ድሕረ-ቅጥያታትን ሰዋስው እዮም።** ንያህዌህ፣ ናይ ያህዌህ፣
ብያህዌህ፣ ካብ ያህዌህ፣ ያህዌህን — ሰዋስው ትግርኛ እዮም፣ ምትካእ ስም ኣይኮኑን።
እቲ ሱር ምሉእ ኮይኑ ይጸንሕ። ዘይፍቀድ: ንሱር ምስባር (*ያዌ*) ወይ ፊደል
ምቕያር (*ይሆዋ*፣ ብዘይ ህ ናይ መወዳእታ *ያህዌ*)።

## ልሙዳት *ኣምላኽ*ን *ጎይታ*ን ሕጋዊ ቦታ ኣለዎም

ዕብራይስጢ ብዛዕባ ኣማልኽቲ ኣህዛብ ወይ ብዛዕባ ሰብኣዊ ጎይታ ኣብ ዝዛረበሉ፣
*ኣምላኽ*፣ *ኣማልኽቲ*፣ *ጎይታ*፣ *ጎይቶት* ብቕንዕና ደው ይብሉ — እዚ ምድምሳስ
ስም ኣይኮነን፣ ትርጉም እዩ። **እቲ `token` ዕብራይስጢ እዩ ዝውስን፣ እቲ ቃል
ትግርኛ ንበይኑ ኣይኮነን።**

## ምልክት ዝተገብረሎም ቃላት

- **ሔሴድ** (חֶסֶד) — ዘይውዳእ ፍቕሪ ኪዳን። "ጸጋ" ጥራይ ኣይኮነን፣ "ምሕረት"
  ጥራይ ኣይኮነን። ሓደ ቃል ትግርኛ ኣይሽከሞን።
- **ሽኦል** (שְׁאוֹל) — ቦታ ምዉታት፣ ከምቲ ዕብራይስጢ ዝብሎ። ገሃነም ኣይኮነን።
- **ማሺያሕ** (מָשִׁיחַ) — **ዝተቐብአ** — ኣብ ደረጃ ታናኽ ፈጺሙ "ክርስቶስ"
  ኣይኮነን፣ "መሲሕ" እውን ኣይኮነን።
- **ቶራ** (תּוֹרָה) — መምርሒ፣ ትምህርቲ። **ברית** → **ኪዳን**።
- **ሻባት** (שַׁבָּת) — ብትግርኛ *ሰንበት* ንሰንበት ክርስትያን ስለ ዝሰምዮ፣
  እቲ ዕብራይስጢ ቃል ብድምጹ ይጽሓፍ።
- **ነፍሲ**፣ **መንፈስ/ንፋስ**፣ **ክብሪ** (נפש፣ רוח፣ כבוד) — ብመሰረት
  ቦታኦም፤ ብሓደ ትሪ ቃል ኣይተኣሰሩን።

ኣስማት ሰባትን ቦታታትን ቅርጺ ዕብራይስጢ ይስዕቡ: **ኣቭራሃም**፣ **ይጽሓቅ**፣
**ያዕቆቭ**፣ **ሞሸ**፣ **ሚጽራይም**፣ **ፓርዖ**፣ **የሆሹዋዕ**፣
**ሻኡል**፣ **ዳዊድ**፣ **ሽሎሞ**፣ **የሩሻላይም**።

## ጥቕሲ ብብርሃኑ

ነፍሲ ወከፍ ጥቕሲ ኣብ ቦታኡ ኮይኑ ዝብሎ ይብል — ኤሎሂም ሓደ እዩ ዝብል እምነት
ዕብራይስጢ (ዘዳግም 6:4) ሒዝና ንንበቦ። ድሒሩ ዝመጸ ትምህርቲ ንድሕሪት
ኣይንስሕብን፤ መጀመርታ ናይ ታሪኽ ብመወዳእታኡ ኣይነንብቦን። ተርጓሚ እቲ ዝተጻሕፈ
ይህብ — ብዘይ ምውሳኽ፣ ብዘይ ምጉዳል።

## ምሉእ ስነ-ስርዓት

እቲ ነዚ ትርጉም ዝመርሐ ስነ-ስርዓት ኣብ ቀንዲ መዝገብ Selah ተጻሒፉ ኣሎ፣
